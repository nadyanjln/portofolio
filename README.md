# Nadya Portfolio — Frontend

Website portofolio modern yang dibangun menggunakan **Vue 3**, **Vite**, **Vue Router**, **Tailwind CSS**, dan **Supabase**.

---

## 🚀 Tech Stack

- **Framework**: [Vue 3](https://vuejs.org/) (Composition API with `<script setup>`)
- **Package Manager / Runtime**: [Bun](https://bun.sh/)
- **Bundler**: [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Routing**: [Vue Router](https://router.vuejs.org/)
- **Backend / Database**: [Supabase](https://supabase.com/) (`@supabase/supabase-js`)
- **Icons**: [Lucide Vue](https://lucide.dev/)

---

## 📦 Instalasi & Menjalankan Project

### 1. Clone & Install Dependencies
```bash
bun install
```

### 2. Konfigurasi Environment Variables (Supabase)
Salin file `.env.example` menjadi `.env`:
```bash
cp .env.example .env
```

Buka `.env` dan masukkan URL serta Anon Key dari dashboard Supabase Anda:
```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-public-key
```

> **Note:** Jika `.env` belum diisi, aplikasi akan tetap berjalan dengan lancar menggunakan fitur fallback / mock simulation otomatis.

### 3. Menjalankan Dev Server
```bash
bun run dev
```

Buka browser di `http://localhost:5173`.

### 4. Build untuk Production
```bash
bun run build
```

## 🗄️ Setup Tabel Supabase untuk Kontak (Opsional)

Jika ingin menyimpan pesan kontak ke database Supabase, jalankan SQL query berikut di SQL Editor dashboard Supabase:

```sql
CREATE TABLE messages (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  email TEXT NOT NULL,
  message TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- Mengizinkan pengiriman pesan dari formulir publik (Anon)
ALTER TABLE messages ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public insert to messages"
ON messages
FOR INSERT
TO anon
WITH CHECK (true);
```
